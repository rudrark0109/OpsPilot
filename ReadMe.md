# OpsPilot - AI Operations Intelligence System

## Engineering Challenge
The project will grow through six increasingly challenging engineering levels.

### 01 — Data Engineering
Consume the SODA3 API, understand SoQL, handle pagination, validate records, and build an incremental ingestion pipeline.

### 02 — Database and Backend Engineering
Design PostgreSQL schemas, optimize queries, implement FastAPI endpoints, and create automated tests.

### 03 — Machine Learning
Train a model that predicts request delays using historical records. Learn feature engineering, data leakage, and model evaluation.

### 04 — Applied LLM Engineering
Integrate an LLM that explains operational trends using verified data and structured outputs.

### 05 — Agentic AI
Build an investigation agent capable of selecting tools, querying records, analyzing patterns, and creating evidence-backed reports.

### 06 — Production AI and MLOps
Containerize, deploy, monitor, benchmark, and evaluate the entire system.
